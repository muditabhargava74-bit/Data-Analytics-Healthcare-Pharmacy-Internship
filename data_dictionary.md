# Data Dictionary

| Field | Data type | Description | Classification |
|---|---|---|---|
| PatientID | String | Synthetic record identifier | Pseudonymous identifier |
| Age | Integer | Patient age in years | Clinical/demographic |
| Gender | String | Gender category in the sample | Demographic |
| Diagnosis | String | Recorded diagnosis | Clinical |
| PrimaryMedication | String | Primary medication listed | Clinical |
| DosageMg | Numeric | Medication dose in mg | Clinical |
| TreatmentDurationDays | Integer | Treatment duration in days | Clinical |
| Readmitted | String | Whether record indicates readmission | Outcome/clinical |
| BloodPressure | String | Systolic/diastolic blood pressure | Clinical |
| CholesterolLevel | Integer | Cholesterol measurement | Clinical |
